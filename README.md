SQL Exploratory Data Analysis

This project focuses on using SQL to explore and analyze sales, customer, and product data and turn raw relational data into meaningful business insights.
I worked through the complete analytical process, starting with understanding the available data and validating its quality, followed by exploratory 
analysis and business-focused querying. The project covers customer and product analysis, sales trends, performance comparisons, cumulative calculations,
segmentation, and other analytical techniques.

Key Areas Covered

- Database and data exploration
- Data quality checks
- Measures and KPI analysis
- Customer and product analysis
- Sales and revenue analysis
- Changes over time
- Cumulative analysis
- Performance analysis
- Customer segmentation
- Part-to-whole analysis
- Business-oriented reporting

Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- Git & GitHub
